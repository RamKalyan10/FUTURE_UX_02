🏠 Fixly – Home Services Booking App UI/UX Design
Fixly is a modern mobile app UI designed to simplify home service bookings for services like plumbing, electrical repair, cleaning, painting, carpentry, and AC servicing.
This project was created as part of the Future Interns UI/UX Internship – Task 2, focusing on designing a complete mobile appointment booking experience for service-based businesses.

🎨 Design Approach
The UI follows a clean and modern mobile-first design approach with:


Minimal layouts


Rounded UI components


Strong visual hierarchy


Easy navigation flow


Conversion-focused CTA placement


The overall experience was designed to reduce booking friction and improve usability for mobile users.
